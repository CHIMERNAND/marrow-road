# Marrow Road

A graveyard tower defense. The dead already know the lane. Hold it through twelve waves, or they reach the chapel.

Gold comes from kills. Spend it on four towers with different reach and prices, then upgrade damage and tempo. A leak costs a life.

- **Wick** — fast lantern fire, short range
- **Ashbow** — long bolts, weak against armor
- **Pyre** — lobbed splash that burns armor
- **Dirge** — a bell that slows everything in reach

Keys: `1`–`4` pick a tower, `Space` calls the next wave, `Esc` clears a selection. On a phone, tap a tower, then tap open grass.

```bash
npm install
npm run dev
```
